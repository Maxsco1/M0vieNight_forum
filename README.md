# Dependencies
* ASP.NET OpenAPI (Microsoft.AspNetCore.OpenApi) v10.0.2
* Entity Framework Core (Microsoft.EntityFrameworkCore) v10.0.9
* An Sqlite3 driver (Microsoft.EntityFrameworkCore.Sqlite) v10.0.9
* .Net Test SDK (Microsoft.NET.Test.Sdk) v18.8.1
* Moq v4.20.72
* NUnit v4.6.1
* NUnit3TestAdapter v6.2.0

# Build instructions
Make sure you're in the root directory (`M0vieNight_forum`) and run
```bash
dotnet build
```

or build and run by substituting `run` for `build` in the above.
